# Путеводитель по проекту INK / STUDIO

Документ для тех, кто не программист, но хочет понять, **где что лежит** и **что за что отвечает**.

---

## Что это за сайт

Сайт тату-студии: каталог эскизов, запись к мастеру, отзывы, личный кабинет и админка для сотрудников студии.

**Технологии (кратко):**

| Слово | Простыми словами |
|--------|------------------|
| **Next.js** | Фреймворк: и страницы сайта, и серверная логика в одном проекте |
| **PostgreSQL** | База данных — всё хранится в таблицах (пользователи, эскизы, записи…) |
| **Prisma** | «Переводчик» между кодом и базой; схема в `prisma/schema.prisma` |
| **NextAuth** | Вход / регистрация / сессия «кто сейчас на сайте» |

## Карта папок

```
tatystudio/
├── public/images/     ← КАРТИНКИ для сайта (эскизы, фото студии). URL: /images/имя-файла.jpg
├── prisma/
│   ├── schema.prisma  ← Описание таблиц БД (что храним)
│   └── seed.ts        ← Начальные данные при первом запуске (админ, эскизы, отзывы)
├── src/
│   ├── app/           ← СТРАНИЦЫ сайта (каждая папка ≈ URL)
│   ├── actions/       ← Действия с сервера (отправка форм, сохранение в БД)
│   ├── features/      ← Формы и блоки UI (запись, отзывы, избранное…)
│   ├── components/    ← Кнопки, шапка, подвал, админ-таблицы
│   ├── services/      ← Чтение данных из БД (запросы без форм)
│   ├── lib/           ← Общие настройки: БД, вход, константы
│   └── widgets/       ← Крупные секции главной страницы
└── .env               ← Секреты и настройки (пароль БД, ключи) — НЕ выкладывать в интернет
```

## Главные сценарии

### 1. Сменить картинку эскиза

1. Положить файл в `public/images/`.
2. Обновить путь в базе:
   - через админку **Эскизы**, или
   - в `prisma/seed.ts` (поле `imageUrl: "/images/ваш-файл.jpg"`) и пересидить БД.

### 2. Запись на сеанс

- Форма: `src/features/booking/booking-form.tsx`
- Сохранение: `src/actions/booking.ts` → таблица `Booking`
- Гость вводит имя/email/телефон; залогиненный — только дату, мастера, комментарий (контакты из профиля).

### 3. Отзывы

- Пользователь: форма на `/o-nas` и в `/kabinet` → `src/actions/reviews.ts`
- В БД создаётся запись с **`isPublished: false`** (не видна на сайте).
- Админ: `/admin/reviews` → кнопка **Опубликовать** → `setReviewPublished` в `src/actions/admin.ts`
- На главной: `src/widgets/home/reviews-section.tsx` — только `isPublished: true`.

### 4. Избранное (сердечко)

- `src/features/favorites/` — кнопка и список
- `src/actions/favorites.ts` — добавить/убрать в БД

### 5. Вход и роли

- Настройка входа: `src/lib/auth.ts`
- Кто может в админку: роли `ADMIN` и `MANAGER` (`src/lib/constants.ts`, `src/middleware.ts`)
- Обычный клиент: роль `USER`

## Папка `src/actions/` — «что происходит при нажатии кнопки»

| Файл | Назначение |
|------|------------|
| `auth.ts` | Регистрация нового пользователя |
| `booking.ts` | Создание заявки на запись |
| `reviews.ts` | Отправка отзыва на модерацию |
| `favorites.ts` | Избранные эскизы |
| `contact.ts` | Форма на странице контактов |
| `admin.ts` | Всё для админки: эскизы, мастера, отзывы, заявки… |

В начале файлов стоят комментарии с подробностями.

## База данных (`prisma/schema.prisma`)

Кратко по таблицам:

- **User** — аккаунты (email, пароль, роль)
- **TattooWork** — эскизы в каталоге
- **TattooArtist** — мастера
- **Booking** — заявки на запись
- **Review** — отзывы (`isPublished` — показывать на сайте или нет)
- **Favorite** — избранное пользователя
- **BlogPost**, **GalleryItem** — блог и галерея
- **ContactMessage** — сообщения с формы контактов
- **SiteSettings** — телефон, адрес, соцсети (редактируется в админке)

## Команды в терминале

```bash
npm run dev      # Запустить сайт локально (http://localhost:3000)
npm run db:up    # Поднять БД + применить схему + seed
npm run db:seed  # Только перезалить тестовые данные
npx prisma studio  # Открыть БД в браузере (удобно смотреть таблицы)
```

## Куда смотреть при типичных задачах

| Задача | Куда идти |
|--------|-----------|

| Права на `/admin` | `src/middleware.ts` |
| Письма / Telegram при заявке | `src/lib/email.ts`, `src/lib/telegram.ts` |
| SEO (sitemap) | `src/app/sitemap.ts` |
