# Папка с картинками сайта

Сюда кладут **все изображения**, которые видны на сайте: эскизы, фото студии, мастеров.

## Как это работает

1. Скопируйте файл сюда, например: `roza-tatu.jpg`
2. В базе или в админке укажите путь: **`/images/roza-tatu.jpg`**
   - В начале обязательно `/images/` (без `public` в пути)
3. На сайте картинка откроется по адресу: `http://localhost:3000/images/roza-tatu.jpg`

## Где менять привязку к эскизу

| Способ | Где |
|--------|-----|
| Админка | `/admin/works` → редактировать эскиз → поле «URL изображения» |
| База при установке | `prisma/seed.ts` → у каждого эскиза поле `imageUrl` |
| Скрипт | `scripts/update-work-images.ts` (если есть) |

## Имена файлов

- Лучше **латиница и без пробелов**: `eskiz-rozy.jpg`
- Пробелы и кириллица в имени тоже работают, но в URL могут выглядеть как `%20` — проще переименовать файл
